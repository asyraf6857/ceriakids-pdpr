# CeriaKids PdPR

Demo GitHub Pages untuk guru prasekolah. **Data disimpan dalam localStorage pelayar sahaja.** Portal guru dan murid tidak berkongsi data antara peranti. Jangan guna data sebenar murid sehingga pengesahan pengguna dan database yang dilindungi disediakan.

Aktifkan GitHub Pages di Settings > Pages > Deploy from branch > main / root.
